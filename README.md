# EBuy Frontend

## Tech Stack

* **Framework:** React (Vite)
* **Routing:** React Router DOM
* **Styling:** Tailwind CSS
* **API Integration:** Fetch API with dynamic token authorization headers
  
## What It's About:
* A modern e-commerce web application built to facilitate seamless online shopping, product browsing, and checkout processes.
* Features a dynamic product catalog, shopping cart management, user authentication, and an interactive seller dashboard.
* Designed to connect buyers and sellers efficiently with a clean and responsive user interface.

## How to Use It:
* Clone the repository and navigate into the project directory.
* Run package installation to set up dependencies.
* Run the development server locally to browse and interact with the application.

## Website Design:
* Built with modern frontend technologies including React, Vite, and Tailwind CSS.
* Integrates React Router for navigation and REST API services with dynamic token authorization headers.
* Fully version-controlled via Git and GitHub with automated CI/CD testing workflows.

  ## Features
  **Product Catalog:** Browse through a dynamic list of items with search and filtering capabilities.
 **Shopping Cart:** Add items, adjust quantities, update total costs dynamically, and manage your cart locally or through state management.
 **User Authentication:** Secure login and registration pages backed by JWT token handling.
 **Checkout System:** Fully integrated checkout form that processes shipping information, calculates order summaries, and posts orders directly to the backend API.
* **Seller Dashboard:** Add new products through an interactive modal and manage seller listings.
 **Responsive UI:** Clean, dark-mode-styled user interface built with Tailwind CSS.


## Conclusion:
* EBuy Frontend provides a robust, user-friendly shopping and selling experience.
* With automated pipelines and structured modular design, it serves as a strong foundation for a full-stack e-commerce platform.
